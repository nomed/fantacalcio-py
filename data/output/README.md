# Output Files - Fantacalcio Analysis

This directory contains the analysis results generated by the Fantacalcio-PY tool.

## Output Formats

The analysis results are now available in **three formats**:

### 1. Excel (.xlsx)
- Traditional spreadsheet format
- Can be opened with Microsoft Excel, LibreOffice Calc, or Google Sheets
- Best for data manipulation and custom sorting/filtering

### 2. JSON (.json)
- Machine-readable structured data format
- Includes metadata (source, total players, generation timestamp, columns)
- Perfect for programmatic access and integration with other tools
- Can be used with web applications and APIs

### 3. HTML (.html) ✨ **NEW!**
- Beautiful, styled web page format
- Can be opened directly in any web browser
- Responsive design with modern styling
- Features:
  - Clean, professional table layout
  - Sticky header for easy scrolling
  - Hover effects for better readability
  - Metadata display with generation info
  - Mobile-friendly responsive design

## Generated Files

- `fpedia_analysis.xlsx` - Excel format of FPEDIA analysis
- `fpedia_analysis.json` - JSON format of FPEDIA analysis  
- `fpedia_analysis.html` - **HTML format of FPEDIA analysis** ✨

When all data sources are available, you'll also see:
- `FSTATS_analysis.*` - FSTATS source analysis in all three formats
- `unified_analysis.*` - Combined analysis from all sources in all three formats

## How to View

### Excel Files
```bash
# Open with default application
open fpedia_analysis.xlsx        # macOS
xdg-open fpedia_analysis.xlsx    # Linux
start fpedia_analysis.xlsx       # Windows
```

### JSON Files
```bash
# View with cat or your favorite editor
cat fpedia_analysis.json

# Pretty print with Python
python -m json.tool fpedia_analysis.json

# Use jq for querying
jq '.players[] | select(.Ruolo == "Attaccanti")' fpedia_analysis.json
```

### HTML Files
```bash
# Open in browser
open fpedia_analysis.html        # macOS
xdg-open fpedia_analysis.html    # Linux
start fpedia_analysis.html       # Windows

# Or simply drag and drop the file into your web browser
```

## Column Descriptions

### Common Columns
- **Nome**: Player name
- **Ruolo**: Player role (Portieri, Difensori, Centrocampisti, Trequartisti, Attaccanti)
- **Squadra**: Team name
- **Convenienza Potenziale**: Potential value index (higher is better)
- **Convenienza**: Current value index (higher is better)

### FPEDIA Specific
- **Punteggio**: Overall score
- **Fantamedia anno X-Y**: Fantasy average for specific season
- **Presenze campionato corrente**: Appearances in current season
- **Trend**: Performance trend (↑ ↓ →)
- **Skills**: Key player skills
- **Consigliato prossima giornata**: Recommended for next matchday
- **Buon investimento**: Good investment indicator

### FSTATS Specific
- **fantacalcioFantaindex**: Fantacalcio fantasy index
- **fanta_avg**: Fantasy average
- **avg**: Average rating
- **presences**: Total appearances
- **goals**: Goals scored
- **assists**: Assists made
- **xgFromOpenPlays**: Expected goals from open play
- **xA**: Expected assists
